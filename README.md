# Bulkmail App

A full-stack MERN Bulk Email application built with React, Node.js, Express, and MongoDB.

Users can:
- Login securely
- Upload Excel files containing email addresses
- Send bulk emails
- View email history
- Track email sending status

---

# Tech Stack

## Frontend
- React.js
- Tailwind CSS
- Axios
- XLSX
- React Router DOM

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Resend Email API

---

# Features

- User Authentication
- Bulk Email Sending
- Excel File Upload Support
- Email History Page
- Responsive UI
- MongoDB Database Integration
- API Integration with Resend
